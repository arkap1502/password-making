Scope: generation draws from the selected character pools using the browser's cryptographic RNG (crypto.getRandomValues), not Python's random module, since the latter isn't safe for real secrets. The field starts empty and is cleared immediately before every new password is forged. You can also type or paste any password directly into the field to score it — nothing you enter ever leaves this tab. Strength scoring mirrors the original rule set — one point each for lowercase, uppercase, digits, punctuation, and length ≥15 — mapped to five bands. This is a generation/scoring tool, not a leaked-password or breach-database check.
