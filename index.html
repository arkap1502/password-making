Strength —
Scope: generation draws from the selected character pools using the browser's cryptographic RNG (crypto.getRandomValues), not Python's random module, since the latter isn't safe for real secrets. Strength scoring mirrors the original rule set — one point each for lowercase, uppercase, digits, punctuation, and length ≥15 — mapped to five bands, and applies the same way whether a password is generated or pasted in. This is a generation/scoring tool, not a leaked-password or breach-database check.
